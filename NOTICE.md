# Notice

This repository contains the ZIF Biocomposite Explorer, an interactive visualisation and exploration interface for ZIF biocomposite datasets.

The software supports ternary composition views, concentration-layer exploration, phase-composition inspection, crystallinity and encapsulation-efficiency views, ATR-IR and XRD spectra inspection, and model-derived prediction overlays.

The software was conceptualised, developed, and maintained by Aleksandar Kondinski at Graz University of Technology.
